## Project Concept
Building a personal brand is a core skill for any software engineer. This initiative, titled **"The Identity Project,"** provided the technical scaffolding for 25 students to launch their digital presence.

## The Curriculum
1. **Design:** Wireframing and prototyping in Figma.
2. **Development:** Translating designs into responsive React components using Tailwind CSS.
3. **Deployment:** Continuous integration workflows using GitHub and Vercel.

## Impact
At the end of the 15-week sprint, 100% of participants successfully deployed a custom URL. Many used these sites to secure summer 2026 internships by showcasing their projects in a professional, high-performance medium.
