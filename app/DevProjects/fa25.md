## Project Overview
This project involved deep-diving into the **xv6 operating system** to implement a custom page table walker. The goal was to manually translate virtual addresses to physical addresses without relying on the built-in hardware MMU for debugging purposes.

### Key Features
* **Virtual Memory Mapping:** Implemented logic to traverse the 3-level page table structure.
* **Kernel Space Protection:** Ensured that user-mode processes could not access restricted kernel memory pages.
* **Memory Dump Tool:** Built a system call that outputs a map of all currently allocated physical pages.

### Challenges
The most difficult part was handling the **PTE_V (Valid)** flags correctly during the walk. Debugging with GDB in a QEMU environment was essential for identifying off-by-one errors in pointer arithmetic.
